# todo-app
A beautiful, mobile-first, zero-dependency to-do web app with dark mode, smart filtering, progress tracking, and swipe-to-delete. Built with vanilla HTML, CSS, and JS.

# 🚀 TaskFlow

A beautiful, mobile-first, and highly responsive To-Do web application designed to help you organize your day with zero friction. Built entirely with vanilla HTML, CSS, and JavaScript—no frameworks, no build steps, just pure performance.

## ✨ Features

- 📱 **Mobile-First Design**: Optimized for touch with swipe-to-delete, bottom-sheet modals, and safe-area insets.
- 🌓 **Dark/Light Mode**: Seamless theme switching with system preference detection and local storage persistence.
- 📊 **Progress Tracking**: Visual circular progress ring and daily stats to keep you motivated.
- 🏷️ **Smart Organization**: Categorize tasks (Personal, Work, Health, Shopping) and set priorities (High, Medium, Low).
- 📅 **Intelligent Dates**: Smart date formatting ("Today", "Tomorrow", "Overdue") with visual indicators.
- 🔍 **Search & Filter**: Instantly find tasks or filter by Today, Upcoming, Pending, or Completed.
- 🎉 **Micro-interactions**: Smooth animations, confetti on task completion, and toast notifications.
- 💾 **Offline Ready**: All data is saved locally in the browser using `localStorage`.
- ⚡ **Zero Dependencies**: No React, no Vue, no build tools. Just fast, clean, vanilla web technologies.

## 🛠️ Tech Stack

- **HTML5**: Semantic markup and accessibility-friendly structure.
- **CSS3**: Custom properties (CSS variables) for theming, flexbox/grid layouts, and hardware-accelerated animations.
- **Vanilla JavaScript (ES6+)**: State management, DOM manipulation, and local storage handling without any external libraries.

## 🚀 Getting Started

### Option 1: Live Demo
View the live application here: [[CLICK HERE FOR TODO APP](https://rohitpatharkar.github.io/todo-app/)]

### Option 2: Run Locally
1. Clone this repository:
```bash
   git clone https://github.com/rohitpatharkar/todo-app.git
```
2. Navigate to the project directory:
```bash
   cd todo-app
```
3. Open the `index.html` file in any modern web browser. Alternatively, use a local server like VS Code's "Live Server" extension for the best experience.
